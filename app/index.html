Unlock admin

Admin mode saves your edits to your GitHub repository. Paste a GitHub token that can write to it. It stays on this computer only.

  1. Open github.com/settings/personal-access-tokens/new
  2. Repository access: Only select repositories → rig-kit
  3. Permissions → Repository → Contents: Read and write
  4. Generate, copy the token and paste it here
